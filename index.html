Student Placement Prediction System using Machine Learning

A Flask web app that predicts whether a student is likely to be placed from academic marks, technical skills, aptitude and reasoning scores and known languages, and highlights their strengths and weaknesses.

  • 🔐
    Authentication & routing: user registration, login and request processing built in Flask.
  • 🗄️
    MySQL integration: stores and retrieves users, student details, mock test questions, test scores and prediction results.
  • 📝
    Mock test module: Aptitude, Reasoning and Technical sections with 10 questions each and automatic score calculation.
  • 🤖
    ML prediction: trained Random Forest and Logistic Regression, chose Random Forest, and loaded it with Pickle in Flask to show results on the web page.
